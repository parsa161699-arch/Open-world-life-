پروژه اندروید OPEN WORLD LIFE - NOVA CITY

این پوشه سورس پروژه Android Studio است و هنوز APK کامپایل‌شده نیست.

نیازمندی‌ها:
- Android Studio
- Android SDK Platform 35
- JDK 17
- اتصال اینترنت برای دریافت کتابخانه Three.js از CDN هنگام اجرای بازی

ساخت APK:
1) پوشه را در Android Studio باز کنید.
2) منتظر بمانید Gradle Sync کامل شود.
3) از منوی Build گزینه Build Bundle(s) / APK(s) و سپس Build APK(s) را بزنید.
4) APK خروجی در app/build/outputs/apk/debug/ قرار می‌گیرد.

نکته:
این پوسته بازی HTML را داخل Android WebView اجرا می‌کند. برای اجرای بخش سه‌بعدی و بارگذاری Three.js اینترنت لازم است.
این نسخه برای آزمایش اولیه است و قبل از انتشار نهایی باید روی چند دستگاه واقعی آزمایش و بهینه‌سازی شود.
